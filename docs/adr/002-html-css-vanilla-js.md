# ADR 002 - HTML, CSS und Vanilla JavaScript

## Status

Akzeptiert

## Kontext

Die Aufgabenstellung schließt moderne Frameworks bewusst aus und fordert eine ältere, einfache Gestaltung.

## Entscheidung

Es werden sechs statische HTML-Seiten, eine CSS-Datei und kleine JavaScript-Dateien verwendet.

## Konsequenzen

Die Anwendung bleibt nachvollziehbar und ist ohne Build-System für das Frontend verständlich.
